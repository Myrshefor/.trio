# trio — инструкции для Code

Этот репозиторий — сам протокол **duo-sync** (бывший trio-sync; см. `README.md`, `HANDOFF.md`). Он использует себя же для отслеживания собственной разработки: `STATE.md`/`INBOX.md`/`DIALOGUE.md`/`LEDGER.md` лежат прямо в корне (не во вложенной `.trio/`, см. `HANDOFF.md` → «Особенность этого репозитория»).

**Если ты открыл этот репозиторий впервые — прочитай `HANDOFF.md` целиком, прежде чем что-либо делать** (сверху — заметка про v0.5.0, остальное — исторический контекст на 30.07). Это полная передача контекста: откуда взялась идея, хронология, инциденты и уроки.

Перед началом любой существенной работы: прочитай `STATE.md` (слоты СЕЙЧАС / ПРОШЛАЯ ЗАПИСЬ / ПОЗАПРОШЛАЯ ЗАПИСЬ) и проверь `INBOX.md` на открытые пункты, адресованные тебе. После значимой работы — обнови `STATE.md` по правилу ротации, ответь в `INBOX.md`, если отвечаешь на что-то из него (статус `answered`).

⚠ Это же правило, что и везде в duo-sync: этот файл (`CLAUDE.md`) — не канал хендоффа. Отчёты, находки, ответы — в `.trio`-файлы этого репозитория (здесь — прямо в корень), никогда сюда.

Полная спецификация — `docs/architecture.md`. Переход с v0.4 и инвентаризация правил — `docs/migration-v0.5.md`. История и инциденты — `docs/history-and-incidents.md`. Исходник плагина — `plugin/`. Прежний протокол — `docs/archive/v0.4.1/`.
