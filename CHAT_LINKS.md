# trio — прямые ссылки для Chat (CHAT_LINKS.md)

_Механизм видимости для Chat через публичный GitHub — см. `docs/architecture.md` §5. Обычный Chat не может сам обойти дерево репозитория и не может достроить ссылку на файл, зная только ссылку на корень — ему нужна точная прямая ссылка, присутствующая текстом в разговоре. Этот файл существует, чтобы такая ссылка на любой из файлов протокола гарантированно оказалась в контексте, если он подтянут в Claude Project (зеркало: `claude/trio-chat-links.md`)._

_Репозиторий: `github.com/Myrshefor/.trio`, ветка `main`. В этом репозитории файлы протокола лежат прямо в корне — см. `HANDOFF.md` → «Особенность этого репозитория»._

_Последняя пересборка: 2026-07-30, Cowork (v0.4.0 upgrade)._
