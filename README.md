# duo-sync (бывший trio-sync)

Файловый протокол передачи контекста между двумя поверхностями Claude на одном проекте: **Claude** (приложение — раньше «Chat» и «Cowork») и **Claude Code** (терминал). Сессии не видят разговоров друг друга; общая папка `.trio/` позволяет любой из них продолжить с того места, где остановилась другая, без пересказа.

Изначально это был trio-sync (Chat + Code + Cowork). Версия 0.5.0 (31.10.2026) убрала всё, что существовало только из-за того, что Chat не видел файлов, и сократила протокол до четырёх файлов.

**Если ты Claude и впервые открыл этот репозиторий — читай `HANDOFF.md`** (контекст и история), затем `STATE.md` и `INBOX.md` в корне.

## Файлы протокола

Внутри проекта — папка `.trio/` (имя сохранено ради совместимости; в этом репозитории файлы лежат прямо в корне):

- **`STATE.md`** — живое состояние: три слота `СЕЙЧАС` → `ПРОШЛАЯ ЗАПИСЬ` → `ПОЗАПРОШЛАЯ ЗАПИСЬ` и `Постоянные требования`. Новая запись сдвигает остальные; вытесненное уходит в `LEDGER.md`, открытое переносится вперёд.
- **`INBOX.md`** — один инбокс вместо `TO_CODE.md` + `FROM_CODE.md`: запросы и ответы с адресатом и статусом. Остаются открытые и два последних закрытых; старше — дословно в `DIALOGUE.md`.
- **`DIALOGUE.md`** — дословный, никогда не тримящийся архив закрытых обменов. Ротируется в `DIALOGUE-archive-<год>.md`.
- **`LEDGER.md`** — переполнение `STATE.md`, append-only.

Подробности — `docs/architecture.md`, маршруты — `docs/scenarios.md`, история и инциденты — `docs/history-and-incidents.md`, переход с v0.4 — `docs/migration-v0.5.md`, старый протокол — `docs/archive/v0.4.1/`.

## Установка

Плагин — папка `plugin/`. Ставится один раз на аккаунт/машину, не на проект.

**Claude (приложение):** открой `.plugin`-файл (или перетащи в чат) — появится подсказка установки. Управление — Customize в сайдбаре.

**Claude Code:**
```
/plugin marketplace add "<путь к папке plugin/>"
/plugin install duo-sync@duo-sync-marketplace
/reload-plugins
```

Старые `trio-sync` / `trio-sync-2` — отключить, иначе сработают оба.

Включить на проекте: «настрой duo-sync здесь» или отдать сессии `NEW_PROJECT.md`. Перенести проект с v0.4: `docs/migration-v0.5.md`.

## Каждый день

Помнить команды не нужно. Начинаешь работу в проекте с `.trio/` — сессия сама читает `STATE.md` и `INBOX.md` и коротко рассказывает, что делала другая сторона. «Какой статус», «догони меня», «передай Code: …», «залогируй это» работают в любой сессии. Таблица фраз — `plugin/README.md`.
