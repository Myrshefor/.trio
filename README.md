# trio-sync

Файловый протокол хендоффа контекста между тремя поверхностями Claude — обычным чатом (claude.ai/desktop, без доступа к файлам), Claude Code (прямой shell/git-доступ на машине разработчика) и Cowork (автономный агент в песочнице/desktop-режиме, доступ к файлам через device-bridge). Три версии Claude, с которыми работает один человек, физически не видят друг друга — каждая начинает с нуля, даже работая над тем же самым проектом. trio-sync решает это простой файловой папкой из пяти markdown-файлов внутри проекта, которую все три поверхности читают перед началом работы и обновляют после значимого шага.

Изначально разработан chyits и Cowork в июле 2026 во время работы над проектом **Finanon** (финансовое приложение — первый «подопытный» проект); теперь развивается как самостоятельный инструмент для любых будущих проектов chyits.

**Если ты Claude (chat, Code или Cowork) и впервые открыл этот репозиторий — читай `HANDOFF.md`, а не этот файл.** README — для людей и беглого обзора; HANDOFF — полная передача контекста для другой модели.

## Файлы протокола

Внутри проекта, который использует trio-sync, появляется папка `.trio/` с этими файлами (в этом самом репозитории они лежат в корне — см. `HANDOFF.md`, раздел «Особенность этого репозитория»):

- **`STATUS.md`** — живой снэпшот: текущий фокус, решения, открытые вопросы, next actions. Перезаписывается на месте, это не история.
- **`LEDGER.md`** — append-only лог, новые записи сверху, коротко (не стенограмма).
- **`TO_CODE.md`** — открытые вопросы к Code от Cowork/Chat. Чистится по мере ответа.
- **`FROM_CODE.md`** — открытые ответы от Code к Cowork/Chat. Чистится по мере получения.
- **`DIALOGUE.md`** — permanent, дословный, никогда не тримящийся архив разрешённых обменов через TO_CODE/FROM_CODE. «Хот-память» переписки, которую можно поднять в любой момент, не поднимая заново весь текущий разговор. Чистится только по явной просьбе пользователя. С v0.4.0 ротируется по достижении порога — самые старые записи целиком переносятся в `DIALOGUE-archive-<год>.md` (те же правила, никогда не тримится), в `DIALOGUE.md` остаётся ссылка на архив.
- **`CHAT_LINKS.md`** (необязательный, v0.4.0) — если `.trio/` лежит в публичном GitHub-репозитории: список прямых ссылок на все файлы протокола, чтобы обычный Chat мог прочитать живую версию любого из них через веб-поиск, зная точную ссылку. Дополняет, не заменяет зеркалирование в Claude Project — см. `docs/architecture.md` §5.

## Роли

- **Code** — hands-on implementer, прямой доступ к файлам и git на машине пользователя.
- **Cowork** — lead strategist, работает в песочнице/desktop-режиме, доступ к файлам через device-bridge, плюс умеет писать в подключённый Claude Project.
- **Chat** — thinking partner и sanity-checker. Не имеет доступа к файлам вообще — видит только то, что Cowork зеркалит в Claude Project (`STATUS.md`, `FROM_CODE.md`, новые записи `DIALOGUE.md`), если этот Project подключён к разговору.

Подробности — `docs/architecture.md` (полная спецификация), `docs/history-and-incidents.md` (история решений и разбор реальных инцидентов, из которых родились текущие правила) и `docs/scenarios.md` (шесть сценариев обмена «кто с кем как говорит», плюс граница `TO_CODE.md` vs device-bridge).

## Установка

Готовый плагин — папка `plugin/`. Упакуй в `.plugin` (zip архива структуры `plugin/*`) и установи:

**В Cowork:** перетащи `.plugin`-файл в чат или открой его — появится подсказка установки. Управлять позже — раздел **Customize** в сайдбаре десктоп-приложения, или настройки скиллов на claude.ai.

**В Claude Code** (на любой машине, ставит плагин глобально для всех проектов):

```
/plugin marketplace add "<путь к распакованной папке plugin/>"
/plugin install trio-sync@trio-sync-marketplace
/reload-plugins
```

## Статус разработки

Этот репозиторий использует свой же протокол для отслеживания собственной разработки — см. `STATUS.md` и `LEDGER.md` в корне.

## Использование день в день

Не нужно помнить команды. После установки:
- Начинаешь работу над проектом с папкой `.trio/` → поверхность сама читает её и коротко рассказывает, что успели сделать остальные.
- «Догони меня» / «какой статус» / «что сделал Code» — в любой момент.
- После значимой работы поверхность сама обновляет `LEDGER.md`/`STATUS.md`. Можно попросить явно: «залогируй это».
- Подключить к новому проекту: «настрой trio-sync здесь» — скилл создаст `.trio/`, включая вопрос про публичный GitHub и `CHAT_LINKS.md` (v0.4.0).

Полная таблица фраз-триггеров (v0.4.0) — `plugin/README.md`, раздел «Quick trigger phrases».
