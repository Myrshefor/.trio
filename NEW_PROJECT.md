# duo-sync — запуск на новом проекте

_Отдай этот файл Claude (приложение) или Claude Code на новом проекте — «прочитай и настрой». Файл самодостаточен: работает, даже если скилл `duo-sync` ещё не установлен в этой сессии. Канонический источник — `plugin/skills/duo-sync/SKILL.md` в `github.com/Myrshefor/.trio`; при расхождении прав скилл._

---

## Кто ты и что делать

Пользователь (chyits) хочет включить **duo-sync** на этом проекте: общую папку `.trio/`, через которую Claude (приложение) и Claude Code видят, что сделано, решено и спрошено другой стороной, без пересказа контекста.

### Шаг 0 — скилл
Если в сессии есть скилл `duo-sync` — следуй ему, а этот файл используй как чеклист. Если установлен старый `trio-sync` — это v0.4, для нового проекта он не подходит: скажи пользователю отключить его и поставить duo-sync (`README.md`). Если скилла нет нигде — не блокируйся, шаги ниже самодостаточны.

### Шаг 1 — спроси только то, чего не можешь выяснить сам
Одним сообщением:
1. Название проекта (если не очевидно из папки или репозитория).
2. Где лежит проект. **Claude (приложение):** не проси сразу вводить путь: проверь подключённые папки → листинг вероятных родителей (Desktop, Documents, домашняя; имена видны и без доступа) → запроси доступ к найденному пути → пользователю печатать путь только если поиск ничего не дал. **Code:** подтверди рабочую директорию.
3. Должен ли `.trio/` быть в git. Сначала посмотри `.gitignore` и существующую структуру; у некоторых проектов (Finanon) `.trio/` внутри репозитория намеренно игнорируется — это уважай.

### Шаг 2 — создай `.trio/` с четырьмя файлами
Подставь название проекта и текущую дату/время.

`.trio/STATE.md`:
```markdown
# <Проект> — State
_Last updated: <дата время> by <Claude|Code>. Rotation: СЕЙЧАС → ПРОШЛАЯ ЗАПИСЬ → ПОЗАПРОШЛАЯ ЗАПИСЬ → LEDGER.md_

## СЕЙЧАС
### <дата время> — <Claude|Code>
**Фокус:** duo-sync подключён
**Сделано:** создана папка .trio/
**Решения:** —
**Открыто:** —
**Дальше:** —

## ПРОШЛАЯ ЗАПИСЬ
_(пусто)_

## ПОЗАПРОШЛАЯ ЗАПИСЬ
_(пусто)_

## Постоянные требования
- Передача между поверхностями — только через .trio/, никогда через CLAUDE.md.
```

`.trio/INBOX.md`:
```markdown
# <Проект> — Inbox
_Один файл для запросов и ответов между Claude и Code. Открытые — сверху; закрытых остаются только два, старше уходят в DIALOGUE.md._

## Открыто

## Закрыто — последняя
_(пусто)_

## Закрыто — предпоследняя
_(пусто)_
```

`.trio/LEDGER.md`:
```markdown
# <Проект> — Ledger
_Newest first. Блоки, вытесненные из STATE.md (ПОЗАПРОШЛАЯ ЗАПИСЬ). Только дописывается._
```

`.trio/DIALOGUE.md`:
```markdown
# <Проект> — Dialogue (verbatim, never trimmed)
_Дословные закрытые обмены из INBOX.md, newest first. Только дописывается. Очищается только по явной просьбе пользователя._
```

### Шаг 3 — подскажи в CLAUDE.md проекта
Добавь (или замени старый блок про trio-sync) в `CLAUDE.md` проекта:

```markdown
## duo-sync
Проект использует duo-sync: общая папка `.trio/` между Claude (приложение) и Claude Code.
Перед существенной работой прочитай `.trio/STATE.md` (слоты СЕЙЧАС / ПРОШЛАЯ / ПОЗАПРОШЛАЯ) и `.trio/INBOX.md` — там то, что адресовано тебе.
После значимой работы обнови `STATE.md` по правилу ротации (подробно — скилл duo-sync и github.com/Myrshefor/.trio/docs/architecture.md).
⚠ Передача — только через `.trio/`, никогда через этот файл.
```

### Шаг 4 — репозиторий
Не нужно ни публичного GitHub, ни зеркал в Project: приложение Claude читает папку напрямую (device-bridge) или подключённый репозиторий. Если `.trio/` в git — закоммить.

### Шаг 5 — скажи пользователю простым языком
Что создано и где. Что работает на обеих поверхностях, только если duo-sync установлен и там, и там (разово на аккаунт/машину). Как проверить: «какой статус» в любой сессии должна прочитать `STATE.md`.

| Фраза | Что происходит |
|---|---|
| «настрой duo-sync здесь» / этот файл | Создаёт `.trio/` |
| «какой статус» / «догони меня» | Читает `STATE.md` и `INBOX.md`, коротко пересказывает |
| «передай Code: …» / «передай Claude: …» | Новый элемент в `INBOX.md` |
| «что ответил Code» | Читает `INBOX.md`, пересказывает ответ |
| «залогируй это» | Обновляет `СЕЙЧАС` с ротацией |
